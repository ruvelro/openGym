# Project provenance

openGym was originally created and published by Duarte Santos under the GNU AGPL v3.0.
In August 2026 the original `DuarteSantos8/openGym` GitHub account was suspended and took the
repository, its published images, the Pages demo and Discussions with it.

This repository is a continuity fork maintained by
[ruvelro](https://github.com/ruvelro). It was recovered through a surviving mirror, repaired
where the vanished account had left hosting, packages and links unusable (this fork's v1.2.5),
and given a sanitized history before continuing development. The mirror was a recovery source,
not an upstream.

The original project later resurfaced at
[gitea.com/DuarteSantos/openGym](https://gitea.com/DuarteSantos/openGym), where its author
continues to develop it. That repository is this fork's upstream today: the two git histories
share no commits (this one began as a snapshot), so upstream releases are brought in by tree
import rather than by merge — upstream v1.2.6 through v1.2.9 were imported that way in this
fork's v1.2.9. Fork-specific pieces (GitHub hosting, `ghcr.io/ruvelro` images, the
`ruvelro.github.io/openGym` site, `render.yaml`) are maintained here.

Historical changelog entries, copyright notices and commits retain their original authorship.
Current project infrastructure, releases and maintenance belong to this repository. When a page
preserves first-person text by Duarte Santos, it is identified as historical rather than being
presented as the current maintainer's story.

One caveat this file exists to record honestly: commits before this fork's v1.2.9 tracked the
exercise media (© Gym visual — see [NOTICE.md](../NOTICE.md)) in the repository. It is no
longer tracked, but it remains reachable in this repository's git history; rewriting that
history has deliberately not been done.
